# 实施范围与验收契约

本项目实现讨论后收敛的双变量首版研究闭环。原提案的多变量图发现（Phase 9）、结构方程恢复、CNN/机器人策略扩展属于后续研究，不属于本版实验结论。

## 必须交付

1. 六类可复现 SCM：线性高斯、线性非高斯、加性噪声、乘性噪声、异方差、独立。保存参数、结构 AST、噪声、观察样本、干预样本与身份。
2. 完整世界隔离 train/dev/extraction/refinement/alignment/test；独立 ID、函数、噪声、尺度、根变量干预测试。生成方向与可识别性约定标签分别保存。
3. 样本置换不变、变量交换等变 DeepSets；可复现训练；冻结 checkpoint 和 SHA-256。
4. 有类型统计 DSL、交叉拟合残差、依赖统计、可执行 AST、复杂度惩罚、beam search。提取监督仅使用冻结网络预测。
5. CEGIS 分开程序—网络不一致与共同因果错误；独立程序引导搜索与等预算随机搜索；测试不进入迭代。
6. 三方评估，按环境/类别统计；决策树、同 DSL 真值监督、无 CEGIS、无复杂度惩罚及 ANM 对照。
7. 冻结网络上的线性标量对齐、源样本内部状态替换与对应程序变量替换；独立测试、随机方向、置换目标控制。
8. CLI、持久化数据/模型/程序/反例/指标、中文说明、静态 HTML 报告、单元和实际端到端测试、独立工件重放验证。

## 科学边界

- 方向识别依赖模型类假设。线性高斯 Unknown 是受控 benchmark 标签，不是从有限样本证明不可识别；其他族也不宣称对全部参数组合有统一识别定理。
- SCM 根变量分布干预与神经内部干预分开。线性高斯负对照在干预测试中保持高斯根变量；其他根变量使用均匀随机化。
- DSL 是人工统计先验。行为 fidelity 不等于内部算法恢复；对齐测试只是对指定映射、变量和干预集的经验支持。
- 隐藏状态最小范数替换可能离开训练分布，因此报告位移，不能把高干预一致率单独当作机制证明。
- 共同错误仅说明错误行为被程序捕获。复杂度惩罚选择短程序，不证明唯一反编译。
- 阴性结果有效。软件验收不要求模型或程序达到漂亮分数。
- 对齐是后验验证，不参与合成；不能声称内部信息改善了合成效率。
- 本版使用受限的显式统计表达式库，不是无限 DSL 搜索。残差采用固定基函数 ridge 两折交叉拟合，HSIC 是归一化分数而非校准 p 值。
- 同 DSL 的真值程序和决策树是必需对照；PySR 是未来可选额外基线，本版不依赖 Julia。
- 所有训练含 ID 数据；无 OOD 训练消融没有单独含义，因为 OOD 数据从未参与训练。泛化直接在五个隔离环境评估。

## 验收方式

运行 pytest；运行默认完整 experiment；独立 verify 重新生成世界、核对哈希、等变性、统计量、程序、指标、干预与报告。完整实验结果及限制记录在 RESULTS.md。
