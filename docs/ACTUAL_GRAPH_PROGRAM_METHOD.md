# 实际多变量图网络的显式程序与干预交换证明

本证明入口处理确认种子 8101、8102 的观察控制与真实干预输入图网络，共四个冻结 checkpoint。对每个网络分别声明 3、5、8 节点域。本阶段只声明数学运算语义下的网络保真，原始 R4、R5、R9 不因此关闭。

## 对象与输入域

输入为任意正整数批量 B 的有限实数张量 F，形状为 B×n×n×24，n∈{3,5,8}。输入包含全部对角 token。被冻结的训练均值、标准差、权重和偏置均按 IEEE 存储值转换为精确有理系数。标准差必须严格正，LayerNorm 的 epsilon 必须严格正。

实际模型源文件的六个完整字节哈希及四个权重文件哈希在证明包中固定。独立验证器重读 state_dict 的全部 22 个参数/缓冲张量，核查系数、激活函数、层数、四个注意力头及归一化配置。目标来自已有确认实验；编译器和验证器不读取真实因果图或结构方程。

本域从已经提供的 24 维特征开始。原始观察样本的统计特征、真实干预查询与响应特征构造仍未包含，不允许把结果改写为原始数据到图的完整恢复。

## 显式计算与局部证书

每个节点规模生成 138 条带类型的张量 SSA 指令：输入归一化、截断、两层 Tanh 编码、出入节点和全局上下文、两层上下文计算、四头注意力、残差与 LayerNorm、完整因子化头、对称化、softmax，以及独立序列化的图决策与后处理。

矩阵乘法的语义为有限乘积和；它不调用隐藏神经模型。显式程序携带实际参数，因此只是计算实现的上界，不是短因果算法或最小因果商。原始最多八项的候选搜索要求与 MDL 缺口保留。

验证器不调用编译器。它逐条核查依赖、系数、形状、索引和局部关系，并检查没有孤立或未证明的指令。有限集合上的均值、求和、最大值、截断等操作均保留其边界。

注意力保留 n² 个查询，仅排除对角键和值，合法键数为 n(n−1)>0。稳定 softmax 的最大项指数为 1，故分母至少为 1。LayerNorm 使用总体方差，方差加 epsilon 至少为 epsilon>0。方向头的完整 log-softmax 中间计算保留，其对数参数至少为 1。最终概率归一化的分母也至少为 1。这些条件允许普通实数除法，不能替换为 CDIR 的保护性除法。

数学上的局部等式以相同自变量调用相同的 Tanh、exp、log 与平方根，无需通过近似数值差来证明这些等式。由计算顺序归纳得到完整分数与概率误差为零。这一证明路径不能被用于证明两个不同表达式的近似等价；后者仍需已有区间后端及严格超越函数包围。

五个图后处理函数的完整 AST 与实际源定义独立匹配：标签决策、贪心无环投影、可达性、字典序拓扑排序及显式 DAG 补全。图后处理的数学解释把 float 转换及 float dtype 视为实数恒等嵌入，数值字面量按其实际存储值解释；真实 NumPy 转换的舍入未获保证。同一数学概率输入经过同一有限分支程序，保留最低索引并列规则、阈值和删环分支。补全出的 DAG 不代表模糊边已被识别，也不保证预测是完成的 CPDAG。

数学保证依赖 PyTorch 2.12 对实际模块的数学规格，以及冻结源代码中调用它们的方式；这不是对 PyTorch/C++ 内核或处理器浮点实现的形式化验证。[LayerNorm 规格](https://docs.pytorch.org/docs/2.12/generated/torch.nn.LayerNorm.html)、[多头注意力的掩码规格](https://docs.pytorch.org/docs/2.12/generated/torch.nn.MultiheadAttention.html)、[缩放点积注意力](https://docs.pytorch.org/docs/2.12/generated/torch.nn.functional.scaled_dot_product_attention.html)。这些基础规格不是本项目创新。

## 固定映射与组合干预

映射在诊断前固定为实际模块的 14 个输出：四个编码层、四个上下文层、注意力输出、LayerNorm 输出、头部线性层和 Tanh、骨架头、方向头。网格与平铺表示通过行优先 reshape 双射对应；注意力只读写返回元组的第一个分量。

允许任意声明站点子集，每个站点可获得各自任意有限实数替换张量，批量、节点和通道形状必须匹配。站点不包含标准差、归一化分母或对数参数。每个子集的下游普通除法与对数均由前述正性关系保证定义。

以 τ 表示固定读映射、ω 表示对应写映射，交换关系为：τ(N^do(ω(I))(F)) = P^do(I)(F)。每个局部等式在同时覆盖输出时仍成立，按拓扑顺序组合，得到全部 2^14 个兼容子集的数学交换保证。不同站点不必使用同一来源张量。

验收同时检查干预目标、中间状态、未干预变量的附带变化和最终输出。附带变化比较的是神经网络与程序变化量是否一致，不要求下游变量保持不变。实际 forward hook 在模块执行后替换输出；程序被覆盖的原始指令明确记录为未求值，不能冒充计算覆盖。使用的物理读写方式依赖 [PyTorch 2.12 forward hook 规格](https://docs.pytorch.org/docs/2.12/generated/torch.nn.Module.html)。未注册站点与其他映射族不在此结论内。

## 浮点诊断与保留的失败

首轮测试包含严格的设备标签相等断言，在四个 8 节点目标均发现近并列分数处的不同标签。原始测试与 JUnit 失败结果保留，后续诊断保存输入生成公式、不同站点的替换公式、干预子集、分数向量和不同标签。

后续测试检查实际读写路径、已观测的数值差和证书是否拒绝设备保证，并持续重放已发现的标签差异。测试通过表示这些检查通过，不能记为设备标签相等通过。近并列区域没有从数学声明域删除；数学等式覆盖该区域，实际浮点标签的全域保证仍未解决。这些浮点观测不是经严格数值包围认证的数学反例。

## 证明包与独立重放

独立证明包包含四个原始 checkpoint、精确数学导出、六个实际源文件、十二份显式程序、局部证书、目标清单与完整哈希清单。验证器重算权重绑定、实际模块映射、所有局部关系及声明覆盖，不依赖工作区的 ncd 导入。

阶段或工件预算耗尽时记录具体未完成域；续跑先独立验证保留的证明包并归档旧版本。少一个目标、节点规模或证书，重新签署外层哈希也不能使验收通过。

当前实现入口为 `python -m graph_ssa_proof prove --config …` 和 `python -m graph_ssa_proof verify-proof …`。统一 ncd 登记与隔离包验收是否完成，以对应冻结的机器记录为准，不在方法文档中预先声明。
