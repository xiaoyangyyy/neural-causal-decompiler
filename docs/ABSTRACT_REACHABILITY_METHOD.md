# Exact action-box closure for the frozen affine 128D ring

The v0.51 two-stage realization has 243 initial states and 4,480 recurrent grid cells in a coordinatewise enclosure of the transition image. That rectangle includes grid cells which cannot be generated by the machine from its initial states. This version computes a smaller, transition-closed abstract graph while preserving the v0.51 simulation certificate.

The initial grid has three bins on each of coordinates `(0,1,2,3,127)` and one on all other coordinates. The recurrent grid has `(16,6,6,6,8)` bins on those active coordinates and one elsewhere. The implementation first verifies the complete v0.51 certificate. It then extracts an exact affine map `f(x,u)=Ax+Bu+b` from the serialized ReLU transition network, proving with rational interval bounds that every hidden ReLU phase is fixed throughout the entire state-action unit cube.

For each abstract source center `c`, and each active target coordinate `i`, calculate exactly

    L_i(c) = (Ac+b)_i + sum_j min(0,B_ij),
    H_i(c) = (Ac+b)_i + sum_j max(0,B_ij).

Every actual quantized action center lies in `[0,1]^5`; hence its successor coordinate lies in `[L_i,H_i]`. Quantize the two endpoints and include every grid index between them. The Cartesian product of these five index ranges may include impossible combinations: it is a conservative overapproximation, not a claim of exact concrete reachability.

Enumerate abstract successors of all 243 initial centers to form `S_0`, then repeatedly add all abstract successors of every recurrent state until a fixed point is reached. This produces 1,952 distinct initial successors, 2,060 recurrent states in the least closure of these conservative abstract edges, and 51,304 enumerated recurrent successor edges. Every retained state is also checked against the prior certified 4,480-cell recurrent rectangle. Exact-fraction replay independently recomputes the whole ordered state list and every count from the frozen network; a changed or truncated certificate is rejected.

The executable `graph_initial`, `graph_output`, and `graph_step` reuse the previous two-stage machine and restrict its recurrent tag to this certified closed set. The prior exact initial-output, handoff, and recurrent simulation inequalities therefore still prove `epsilon=17/100` for every unit-cube initial state, every continuous unit-cube action word, and every finite horizon. Closure ensures no executable transition leaves the 2,060-state recurrent set. The action intervals bound every continuous action even though the machine internally quantizes actions to 128 bins per coordinate.

The result is a deterministic 2,303-state realization, so the same-model general minimum lies in `[162,2303]` using the independent 162-state packing lower certificate. The lower certificate uses the binary64 value `0.17`, which is slightly larger than exact rational `17/100` in the upper certificate. Neither the 2,060 retained abstract cells nor the 51,304 conservative edges are asserted to be precisely concrete reachable. This proof does not establish a globally minimal finite realization or certify the other trained nonlinear networks.
