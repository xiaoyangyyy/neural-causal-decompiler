# 后续多变量恢复审查

当前 V2 的 3/5/8 节点完整图恢复仍有明显失败。已有双变量联合数值与内部评分流程不能替代该缺口的解决。

## 已直接检查的结构

ncd/graph_model.py 将 n×n 的成对统计表示展平成 n² 个 token，执行无位置的集合注意力，只屏蔽对角 token。没有显式向注意力提供“共享源节点、共享目标节点、首尾相接”等边关系。

这不等于证明网络无法间接推断端点关系：成对统计中可能含有可辨别的节点统计特征。当前代码证据仅支持“没有显式端点关系编码”，不能据此断言这是所有图恢复错误的唯一原因。

## 下一项可检验实现

在保持变量置换等变、样本置换不变的条件下，加入共享端点和两跳路径的关系信息。现有冻结教师与结果必须保留；新模型是明确标识的新架构比较，不能冒充从旧网络中恢复了已有算法。

应保持相同世界、统计前端、训练预算及图解码规则，对照有/无关系信息。评估不能只看大量无边带来的整体 pair accuracy；必须报告宏 F1、方向识别、骨架、SHD、整图与按图大小分列的结果。

提取程序与显式 SCM 恢复需要继续对新旧模型分别审计，且要保留神经预测、局部规则、无环投影的不同贡献。条件分离集和 collider 规则仍须区分人工基线与实际提取结果。

正式种子、数据量和超参数在具体实现及集成测试完成后单独冻结；不能回用既有测试结果挑选最优设置。
