# Fixed-instance truth gap after frozen three-node acceptance

This protocol separates candidate construction from the true-world evaluator. The candidate package reads only three frozen mechanism checkpoints and the accepted child proof. It first proves a mathematical real-arithmetic program bound for the deterministic learned three-node neural system under every compatible simultaneous node intervention. The true-world evaluator can run only after the candidate bundle and its independent acceptance receipt have immutable SHA-256 anchors.

The fixed true world is the historical n3_test_id_0 world from active_end_to_end_seed4993. Its world.json and enclosing run manifest have frozen hashes in the truth-only evaluator. In this instance the true graph and the learned checkpoint graph happen to agree: nodes 1 and 2 are roots and both parent node 0. Graph agreement here is a diagnostic for one instance, not a graph-recovery theorem.

For each root, the true structural function is exactly zero in the observed coordinates. The evaluator independently exports the frozen neural checkpoint and computes a rational interval enclosing its ideal real output over [-1,1]^3. Let s_j be its frozen output training scale and eps_j = s_j/100. If the interval is strictly separated from zero by more than 2 eps_j, then no scalar program P_j can satisfy both sup |P_j-H_j| <= eps_j and sup |P_j-f_j^true| <= eps_j on that box: the triangle inequality would force |H_j-f_j^true| <= 2 eps_j at every point. The evaluator additionally checks that the sealed extracted constant root program meets neural fidelity and itself has a strict true-mechanism gap.

This refutes only the simultaneous one-percent training-scale neural-and-true root fidelity claim for these fixed frozen checkpoints and this fixed world. It does not refute the possibility of recovering another network's true mechanisms, the child mechanism, the causal graph in general, or intervention distributions. It does not change the original R0-R13 atomic ledger merely because the stronger combined claim fails here.

The independent evaluator checks the composition acceptance hash and candidate manifest before it reads any true-world bytes. Its separate bundle archives the historical manifest, world, candidate acceptance, protocol, and recomputed certificate. A verifier re-derives the strict rational margins from the archived checkpoint and true-world evidence. The stage runner imposes a 12-hour limit, two computation threads, an 8 GiB descendant memory limit, and an 8 GiB artifact cap. A final acceptance gate requires both installed-package prove and replay stages, two positive root margins, the exact historical hashes, and the source regression tests. Both isolated prove and verify stages passed, and validation/frozen_truth_gap_acceptance_v1.json accepted the scoped refutation. The strict two-target incompatibility margin lower bounds are about 0.0212100190 for root 1 and 0.0240793564 for root 2. The portable bundle is runs/frozen_three_node_truth_gap_v1. The original 38-atom ledger remains 0 proved, 2 refuted and 36 unresolved.
