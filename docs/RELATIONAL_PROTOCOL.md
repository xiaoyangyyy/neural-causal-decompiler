# 显式边关系注意力：预先固定的对照协议

本协议在正式运行前固定。seed 491 仅用于小规模集成检查。正式种子为 493、494，不复用既有实验的最终测试世界选择参数。

## 对照对象

两个新教师具有相同的统计前端、共享权重初始化、参数分配、优化器、最大 epoch、开发集选择准则和图解码规则。差别是边关系偏置的开关。

关系类型：同一边、反向边、共享源、共享目标、后继边、前驱边。使用学习的每头偏置，保持节点置换等变。旧 GraphDiscoverer 与所有历史 checkpoint 保留不变。

参数分配相同不等于有效自由度相同：禁用版的关系偏置固定不起作用，启用版可以学习这 24 个偏置。因此这是明确的关系信息/有效容量对照，不声称只改变了无参数的输入格式。

## 固定预算

- 节点数 3、5、8；样本行数 96。
- 每种节点数：训练 256 世界、dev 64、程序提取 128、反例修正 64；五类独立测试各 96。
- 每个正式种子合计 2,976 个世界，由两个模型共享。
- 神经训练 40 epochs，width 48，类别加权训练交叉熵；checkpoint 仅按未加权 dev 交叉熵选择。
- 每个教师分别提取局部程序：相同语言、最多 6 次分裂、beam width 3；相同修正集与最多 256 个教师不一致样本。
- 每种节点数预先固定 test_id 的索引 1、2，用于机制恢复，不能按图预测正确性挑选世界。
- 每个世界分别使用两个推断图，以及共同真实图诊断，合计每种子 18 次机制恢复；每次 512 行、160 epochs。

## 评估与验收

神经原始图、神经无环投影图、符号原始图、符号投影图分别报告宏 F1、骨架 F1、方向准确率、pair SHD 和整图准确率。记录投影删除的边，不能把后处理收益归因于注意力关系。

显式 SCM 记录父集准确比例、符号/神经误差、真实机制误差与干预效应误差。高斯任务目标仍为 CPDAG，不确定边补成 DAG 的具体选择会保留，不能将该补全当成识别出的方向。

独立重放检查数据生成、训练集归一化、dev checkpoint 选择、控制开关、神经预测、规则重新合成、图投影、机制父集来源、符号拟合重算和干预指标。

这是新的结构对照实验，不是“从旧网络反编译出了端点关系算法”的证明。即使神经图改善，局部程序仍可能无法表达全部关系上下文；必须分别报告图准确性与程序保真。
