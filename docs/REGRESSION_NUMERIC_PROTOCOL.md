# Cross-fit regression mechanism protocol

Frozen after quick seed 992 and before formal seeds 993/994. Seed 993 uses joint-191;
seed 994 uses joint-192. Quick 992 is excluded from scientific summaries.

Every one-dimensional cross-fit regression in the raw CDIR is expanded into two
folds. Per fold the trace exposes predictor mean, predictor standard deviation,
and five coefficients for the fixed basis [1, z, z^2, sin(z), tanh(z)]. The two
causal directions produce 28 structural-equivalence groups; each group synchronizes
the duplicate occurrence used by residual dependence and residual error features.
Unmodified execution must reproduce the existing CDIR features exactly.

Within a fold, mean and standard deviation precede all coefficients; their joint
intervention with a coefficient is excluded. Coefficients are parallel and may be
paired. Pair acceptance uses symbolic execution only.

Each formal run uses 1,024 fit worlds, 4,096 disjoint test worlds, 96 samples,
384 non-reused singleton training pairs, and 1,024 non-reused compatible singleton
or pair test groups. All three neural cuts use 28 rank-one jointly orthogonal blocks,
120 updates, numeric weight 0.5, plus behavior-only, shuffled and random controls.
No final-test site selection is allowed.

Report per-step natural, targeted, baseline and collateral NMSE and categorical
interchange results. This finite audit does not establish unique coordinates or
complete causal abstraction, even if coefficients can be read out.
