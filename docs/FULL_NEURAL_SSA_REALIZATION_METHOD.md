# Full fixed-network primitive realization

Let F be the real mathematical interpretation of the source-bound Discoverer
with the exact values of its loaded finite weights and Python scalar constants.
Let P be the typed scalar/vector SSA artifact. Each real FX tensor coordinate
has exactly one distinct writable SSA coordinate. The checker extracts F anew,
checks rational affine normal forms, reductions, scalar/vector broadcasting,
protection premises, both normalization/encoder/head branches, and every
primitive instruction. All local relation errors are exactly [0,0].

Topological induction gives tau(F^do_s(x)) = P^do_s(x) for every finite N x 2
input, N >= 16, and every subset of mapped coordinates. Each selected coordinate
receives the identical independently supplied finite source value on both sides;
vector sources have base N, scalar sources may have different N. Positive scale
sites and their log aliases must meet the frozen floor. Unpatched coordinates
use their checked local relation, including collateral changes. Floor, clip,
and lowest-index argmax boundaries and ties remain in the scope. A patched
conditional has no visited conditional child and is excluded from branch-access
coverage. Scalar/vector intermediates are computation coordinates, not claimed
recovered scientific causal variables.

The compiler proposes. The verifier independently checks all affine coefficients
and graph dependencies; recompilation identity is not the affine proof. It
rejects altered weights, source bytes, programs, local relations and stronger
scope flags. Canonical JSON hashes bind source protocol, target graph and weights,
program, local proof and diagnostics. No ground-truth graph or equation enters
compilation. Unsupported computation/failed budgets do not yield a proved file;
retained checkpoints cannot close the original requirement.

Numeric execution uses NumPy and no Torch/neural module. Rational outward interval
execution uses the original ncd.proof_intervals transcendental remainder bounds.
Floor guards refine the false child to std >= floor, preserving a positive
protected-division denominator even when a box straddles the boundary. Possible
classification labels remain explicit when a margin cannot be resolved. These
bounds concern real mathematical operations, not the original hardware's float32
rounding. The actual FX diagnostics deliberately run float64 and are separately
reported empirical checks.

This lowers the whole learned computation, including both learned encoders and
heads. Its tens of thousands of instructions and numerical weight constants are
an implementation/description upper bound. It is not a theorem that a short
causal algorithm, a minimal quotient, a unique minimal semantics or a correct
SCM has been recovered. No stronger original atomic claim is silently closed.
