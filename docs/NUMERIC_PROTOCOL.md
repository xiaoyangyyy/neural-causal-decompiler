# 数值中间机制实验协议

本协议在正式数值实验启动前固定。seed 291 的 quick 运行仅用于集成检查，不作为最终确认结果；没有按其最终数值误差挑选隐藏位置或超参数。

## 固定对象与世界

- 正式种子 293：冻结 runs/joint_seed191 中的教师 checkpoint 和程序。
- 正式种子 294：冻结 runs/joint_seed192 中的教师 checkpoint 和程序。
- 不重新训练教师。来源文件哈希记录在 config.json，实验中拷贝保留，重放检查一致。
- 每次拟合世界 1,024，独立测试世界 4,096，每个世界 96 行。只在拟合集筛除执行少于 8 次或数值方差不足的操作数，记录全部被排除位置。
- 研究对象为已提取规则中的数值叶操作数；这些操作数引用统计特征。尚不等于自动恢复原始样本到统计量的整段计算。

## 固定方法与控制

隐藏位置全部报告：representation、head_linear、head_tanh。此次不使用测试结果选位置。

数值读出仅用拟合集拟合，之后冻结；映射在教师和读出均冻结的条件下训练。映射秩 1，120 步，数值损失权重 0.5。仅单变量干预参与拟合，所有结构兼容的双变量组合属于未见组合。

控制：相同预算的仅行为损失、打乱标签及数值目标、同维随机正交映射。所有方法使用相同独立测试配对，原始类别和未干预数值误差作为基线保留。

## 配对与统计解释

每个配对只消耗一个基世界及实际活跃变量的源世界，接受和拒绝的世界均不复用。按程序结构删除互斥分支及相互遮蔽的组合，再仅根据符号可达性接受配对，不查询神经输出或真实因果标签来筛选。

因此指标描述“符号执行条件下”的干预分布，不是无条件 SCM 风险。固定请求最多 1,024 对，但真实接受量由世界预算决定；不足时按实际数量报告。必须报告未见组合的覆盖与有效数量，不能用合计数字替代组合外推证据。

## 验收及仍未完成

ncd.numeric_experiment 的 verify 检查数据生成、源模型、操作数选择、配对、线性读出重拟合、全部数值/行为指标和控制工件。另有正对照证明数值检验能区分类别结果相同的错误变量映射。

数值读出仍只是探针；低数值误差与干预一致不能单独证明唯一真实机制。多层选择接回程序合成、完整数值算子自动发现、图和 SCM 恢复仍须继续实现与验证。
