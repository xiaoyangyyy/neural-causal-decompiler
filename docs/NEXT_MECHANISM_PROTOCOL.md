# 后续完整机制验证协议（V2 之后）

本文件记录尚未完成的原始目标的下一步实施要求，不是完成证据。V2 的两个正式种子与安装包冻结保留。

## 要解决的缺口

当前最终审计只选择一个统计量映射到一个隐藏子空间。通用多层 hook 的存在不能证明完整程序的多个中间步骤已对应网络内部机制；行为提取也仍有约三成误差。下一阶段不能仅扩大随机种子数量或重复现有测试来宣称目标已完成。

## 实现与评估顺序

1. 对可执行 Rule/Node 提供稳定节点标识、执行轨迹和具类型检查的中间节点干预。支持统计量、复合表达式及比较节点，保存实际被访问的分支。禁止通过修改网络权重来满足程序。
2. 对多个高层中间变量联合学习低层映射。先在同一隐藏层使用不重叠的正交子空间块，并允许通用追踪接口支持不同调用位置；明确记录支持与尚不支持的图结构。
3. 在拟合阶段同时训练单变量干预和变量组合；留出未见世界及未见组合。不同候选层、变量、秩只能在验证集上选择，最终测试只执行一次。
4. 报告每个节点和组合的基线一致、符号改变、有效覆盖、干预一致及不复用世界的样本量；不能仅报告总体不变输出占优的一致率。统计量替换是高层程序干预，不谎称每个替换组合都对应真实可实现 SCM 数据。
5. 对照必须包括同维随机映射、变量映射置换、打乱目标拟合、未干预教师，以及单变量 V2 映射；所有比较使用相同源/目标对。
6. 将验证中得到的机制一致性用于程序选择，再做完全独立的无内部信息消融；不能把最终测试对齐结果回填合成。
7. 增加可验证的已知多步骤神经算法正对照，只用于验证工具正确性；原有自由训练网络仍是主要研究对象，不得用正对照替换它。

## 数据冻结

下一阶段预设种子 191、192；沿用完整世界级 split 隔离，并单独划分组合干预的拟合/验证/测试集合。V2 的 91、92 结果仅用于记录已发现的问题；不得对其调参再称独立确认。

## 成功条件

软件层：中间执行/干预重放、联合映射维度与互斥约束、教师冻结、世界与组合隔离、安装包运行均可验证。

研究层：报告多步骤覆盖程度及失败，不预先假定成功；只有在保真、组合干预及控制对比上得到支持的部分，才可称为相应范围的内部恢复。图发现与 SCM 父集/算子恢复仍需独立提升，不能由该实验代替。
