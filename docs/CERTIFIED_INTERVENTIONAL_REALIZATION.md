# Certified Interventional Realization

## Claim and scope

Version 0.27 implements three certified layers: exact finite realization,
finite L-infinity approximate realization, and a finite-horizon continuous
ReLU separation oracle. The exact finite object is a deterministic Moore system

\[
\mathcal N=(S,A,F,O),\qquad R(s,w)=O(F^*(s,w)).
\]

'S' is a declared complete, finite, action-closed set of resettable internal
state handles. 'A' is a fixed set of labelled admissible actions. Action labels
cannot be relabelled by the abstraction. Outputs are JSON values compared by
exact canonical equality.

The exact claim is limited: the emitted certificate proves the minimal number of
states required to reproduce 'R(s,w)' for every declared state and every finite
action word in \(A^*\). The later sections state the separate finite-approximate
and continuous-pair claims. None of these certify unknown reachable states,
stochastic dynamics, or real-world causal validity.

## Exact equivalence and quotient

Define

\[
s\equiv t \iff \forall w\in A^*,\ R(s,w)=R(t,w).
\]

This is a right congruence. If \(s\equiv t\), then for every action \(a\),
\(F(s,a)\equiv F(t,a)\); otherwise a distinguishing suffix for the successors
would make its action prefix distinguish 's' and 't'. Therefore

\[
\bar F([s],a)=[F(s,a)]
\]

is well-defined. The implementation computes the quotient by Moore partition
refinement over outputs and labelled successors.

Every exact realization must keep inequivalent states separate. The quotient
is consequently minimal and any other minimal deterministic Moore realization
over the same action labels is isomorphic up to state renaming. These are
classical finite-state results used as foundations, not claimed as new theory.

## Two independently checkable certificates

The upper certificate contains a candidate system, a total surjective encoding
\(\pi:S\to Q\), and the declared scope. The verifier checks every state and
action:

\[
O(s)=\bar O(\pi(s)),\qquad
\pi(F(s,a))=\bar F(\pi(s),a).
\]

These finite checks imply exact agreement for every word by induction, giving
\(K_{\mathcal N}(0,A^*)\le |Q|\).

The lower certificate chooses one concrete representative from every proposed
abstract state and supplies a response word for every pair. The verifier
re-executes all witnesses and requires unequal responses. The representatives
are a pairwise distinguishable set, so every exact realization needs at least
that many states. When the two bounds coincide, minimality is certified.

The checker does not trust stored responses, state counts, metrics, mappings,
or hashes. Artifact hashes detect ordinary corruption; deterministic
regeneration and semantic certificate checks detect a modified artifact whose
hash was recomputed.

## Response-only active recovery

The learner receives:

- the complete list of resettable state handles;
- the labelled action alphabet;
- query access to 'R(s,w)'.

It does not read the transition table. It begins with suffix set
\(E=\{\epsilon\}\) and groups states by their response rows over 'E'. For
every current block and action, it queries derivative rows

\[
\big(R(s,aw)\big)_{w\in E}.
\]

If two states in one block have different derivative rows, the corresponding
'aw' is added as a distinguishing suffix. If every block is consistent, the
complete action-closed state-list assumption guarantees that every derivative
row matches the row of a declared successor state. These matches define the
candidate labelled transition system.

The result is exact when closure and consistency have been established. A
separate table-aware verifier then checks the candidate homomorphism and all
lower witnesses. This distinguishes learner access from verifier access:
response queries construct the candidate; the independent checker may read
the finite transition table to certify the global statement.

If a query budget stops the table before closure and consistency, equal rows
are reported as 'unresolved'. They are never relabelled as equivalent.

## Benchmark protocol

Each deterministic benchmark case is generated by first sampling a minimal
base transducer and then splitting its abstract states into multiple physical
states. The resulting table is compiled into an explicit two-layer ReLU
transition network and linear neural observation head. The evaluator enumerates
the network's actual argmax transitions and outputs; this enumerated neural
system, rather than the hidden construction table, is ground truth. Split
states can have different concrete successors while retaining exactly the same
future behavior.

Four evaluations are stored:

1. transition-table enumeration and the exact oracle quotient;
2. response-only active recovery and its independently checked certificate;
3. equal-query-budget random experiments, passive short traces, and activation
   clustering;
4. deliberately budget-limited recovery with separated,
   merged-certified, and unresolved pair counts.

The trained-network analogue of the benchmark is the concrete finite
transducer itself. Recovery is compared with its actual minimal quotient, not
with the program or task used to create it.

Run and replay:

    python -m ncd certified-finite --output runs/certified_finite --seed 2701
    python -m ncd verify-certified-finite runs/certified_finite

Use '--quick' for a three-case integration run. Output directories are never
overwritten.

## Approximate realization

For \(\epsilon>0\), thresholding a response metric does not generally define
an equivalence relation. The intended later object is the optimization

\[
K_{\mathcal N}(\epsilon,\mathcal W)=
\min_{\mathcal M,\pi}|Q|
\quad\text{s.t.}\quad
\sup_{s,w\in\mathcal W}
D(R_{\mathcal N}(s,w),R_{\mathcal M}(\pi(s),w))\le\epsilon.
\]

Pairwise separation above \(2\epsilon\), when 'D' is a metric, provides a
valid lower-bound witness. Pairwise distances below \(2\epsilon\) do not
provide an upper certificate. Three outputs at the vertices of an equilateral
triangle of side \(1.9\epsilon\) are pairwise compatible but cannot all lie
within \(\epsilon\) of one representative. Transition consistency adds
further constraints.

Version 0.27 implements this finite approximate problem for numeric scalar or
vector outputs under the L-infinity metric. The separation oracle explores the
finite product transition system, so each lower-bound edge has an exact
maximizing witness. An exact graph-coloring computation certifies the
incompatibility lower bound. The upper search emits a total encoding, a
coordinatewise center for each abstract output, and an exact labelled
transition homomorphism. The checker independently recomputes the chromatic
number and checks every output error and transition. When lower and upper
coincide, the general realization complexity is pinned down even though the
upper search uses a stronger homomorphic candidate class.

## Continuous neural separation oracle

For a recurrent ReLU system, two fixed initial states, a finite horizon, and a
box of continuous intervention words, the implementation now certifies

\[
LB(s,t)\le \sup_{w\in\mathcal W}
\max_{0\le j\le H}\|O(s_j)-O(t_j)\|_\infty\le UB(s,t).
\]

A feasible intervention word supplies the lower bound. The upper bound uses
interval propagation through every affine and ReLU layer. Every scalar
multiplication and addition is rounded outward with `nextafter`. A deterministic
branch-and-bound tree partitions the complete intervention box; its leaves are
a cover, not samples. The verifier reconstructs that cover, recomputes every
leaf bound, and rechecks the feasible witness.

Version 0.28 adds a relational upper bound for paired executions receiving the
same control word. Shared control terms and affine biases cancel in the
difference recurrence whenever both executions have a certified common ReLU
phase. If phase stability cannot be established, that leaf falls back to the
independent interval bound. The formal scaling study reaches 128 latent
dimensions, five controls, and horizon 20 in the stable-phase regime; details
are in `docs/CONTINUOUS_SCALE_METHOD.md`.

The result has exactly three statuses. `separated` requires `LB > 2 epsilon`;
`certified-within-epsilon` requires `UB <= 2 epsilon`; every remaining interval
is `unresolved`. Increasing the leaf budget may close an unresolved interval,
but exhausting a budget never becomes an equivalence claim.

Certified separated pairs form an incompatibility graph. For a declared finite
collection of continuous neural states, the checker verifies every pair
certificate and recomputes the exact chromatic number. This proves a realization
complexity lower bound for that state collection and intervention domain.

For horizon one, the implementation can also verify a supplied finite candidate
whose transition is a certified partition tree over the continuous action box.
It checks the initial output error for every declared neural state and propagates
every action leaf through the original ReLU transition and observation networks.
The frozen benchmark closes at epsilon 0.3 with a two-state candidate and a
chromatic lower bound of two, hence `K=2` for that declared state collection,
continuous action interval, metric, and horizon.

Run and replay the frozen benchmark:

    python -m ncd certified-continuous --output runs/certified_continuous
    python -m ncd verify-certified-continuous runs/certified_continuous

The continuous result is deliberately narrower than a complete continuous-state
minimal realization theorem. It certifies fixed state-pair separation queries
and closes one candidate realization over a declared finite initial-state
collection. It does not provide a finite abstraction with a uniform fidelity
proof over an uncountable initial-state domain, and it does not claim that
interval propagation will close every query. That global extension remains an
open research problem.
