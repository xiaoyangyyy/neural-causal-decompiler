# 固定实验协议

## 预设预算

默认 seed=42；每世界 96 行、2 个变量；网络宽度 48、40 epochs，以 dev 最低交叉熵选取 checkpoint。训练 2,400 世界；dev 384；提取 768；修正 512；对齐拟合 384；对齐测试 384；每个最终测试环境 384；攻击候选池 512。

五个最终环境为 ID、函数 OOD、噪声 OOD、尺度 OOD、根变量分布干预。线性高斯和独立类是负对照，函数 OOD 仅改变有非线性机制的三个族，噪声 OOD 保持线性高斯对照为高斯。所有统计结果使用整个世界作为样本单位。

程序 beam_width=4，max_splits=4，penalty=0.001；阈值为提取数据统计分位数。CEGIS 两轮，每轮最多补充 64 个未使用的网络不一致世界，名额按类别分配后填满剩余额度。这里的 CEGIS 是有限候选池上的反例引导归纳，不是形式化完备验证器。

攻击比较最多各查询冻结网络 64 次；候选池独立于修正池。程序引导优先选择程序与生成真值不同的世界；随机策略在同一池随机抽样。程序搜索阶段和攻击评估阶段允许的真值访问不同，代码分别实现。

## 对齐拟合与验证

拟合集的前 70% 拟合 ridge，后 30% 选择程序使用的统计原语；然后使用整个 alignment_fit 重拟合该标量映射。测试集永不参与选择。对齐基于两个交换方向表示的拼接向量，干预为在标准化表示中沿解码方向进行最小范数替换，使其解码值等于源世界的统计值。程序同步替换同一原语。

源世界索引为固定循环位移，因此没有自我替换；随机方向和打乱目标控制使用固定独立 RNG。报告整体一致率、原来一致子集、一致且符号结果发生变化子集、状态位移和标量解码误差。

该设计并不保证神经内部实际自然计算了相同统计量，也不保证补丁在表示流形上；本阶段是可重复的机制候选审计。

## 预先固定的解释规则

- fidelity 高只能支持行为替代模型。
- 对齐结果必须同时看控制组与有效子集数量；不以整体一致率 alone 宣称内部机制恢复。
- 程序引导共同错误率与随机相比仅报告差值；单个候选池和一个随机控制没有显著性结论。
- ID 分数不能代表 OOD。不同世界族汇总也不能掩盖类别表现，逐类指标保存在 JSON。
- 阴性结果必须保留，不修改测试集或挑选种子追求正结果。
- AST 复杂度惩罚属于 MDL 风格启发式，不是严谨编码长度下的最优性保证。

## 后续扩展条件

本版先建立可信闭环。后续若要主张机制恢复，需要多个训练种子、更多对齐控制、未见干预家族和比当前标量映射更强的候选比较；若要多变量扩展，必须另行定义 CPDAG/可识别目标、分离集保存与全局一致性，不能简单把双变量规则合并成图。
