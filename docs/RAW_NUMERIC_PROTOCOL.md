# Raw statistical mechanism protocol

This protocol was frozen after the 792 integration run and before formal seeds 793
and 794. Seed 793 uses the frozen joint seed-191 teacher/program; seed 794 uses
seed 192. The prior 792 run is an integration artifact and is excluded from claims.

## Targets

The declared raw CDIR feature ASTs are executed before the extracted Rule. Every
structurally identical internal scalar occurrence is intervened as one equivalence
group. The eight fixed groups are mean(X), mean(Y), variance(X), variance(Y),
standard deviation(X), standard deviation(Y), correlation, and the variance ratio.
This tests internal operations below final feature leaves. It does not expose the
inside of the dependence kernel or cross-fit regression yet.

## Isolation and budgets

Each run uses 1,024 new alignment-fit worlds and 4,096 new alignment-test worlds,
96 samples per world. World identities cannot repeat across splits. Linear probes
and mappings use fit worlds only. Training uses 384 execution-conditioned, non-reused
single-group interchange pairs. Testing uses 1,024 non-reused pairs covering every
compatible singleton and pair; ancestor/descendant group pairs are excluded before
sampling. Rejected groups consume worlds and are never recycled.

All representation, head-linear, and head-tanh cuts are reported. Each group receives
a rank-one jointly orthogonal block. Training uses 120 updates and numeric weight 0.5.
Controls are behavior-only, shuffled targets, and a seeded random orthogonal basis.
The teacher and fit-only readout stay frozen.

## Evaluation

Report natural probe NMSE, targeted and collateral NMSE, behavior interchange
accuracy, informative-pair counts, and held-out compatible pair combinations.
Numerical intervention fidelity is interpreted against the no-intervention baseline
and controls. No neural site is selected from final test results. Passing software
replay cannot establish unique mechanisms or complete causal-discovery algorithms.
