## Certified finite interventional realization (0.27)

The primary workflow constructs and independently verifies the exact minimal
realization of a finite deterministic neural transducer. The learner uses
response queries only. The verifier checks output/transition preservation and
pairwise distinguishing witnesses. A stopped run retains unresolved pairs.

    python -m ncd certified-finite --output runs/certified_finite --seed 2701
    python -m ncd verify-certified-finite runs/certified_finite

See [Certified Interventional Realization](docs/CERTIFIED_INTERVENTIONAL_REALIZATION.md)
for the formal scope, proofs, access assumptions, and approximate-case boundary.
Older symbolic and SCM workflows remain available as baselines.

The traffic stress test trains quantized latent dynamics under five natural
control actions and certifies the trained network's finite realization:

    python -m ncd certified-traffic --output runs/certified_traffic --seed 3701
    python -m ncd verify-certified-traffic runs/certified_traffic

The continuous ReLU separation oracle certifies lower and upper bounds over a
bounded continuous intervention word, preserves unresolved queries, and builds
a verified incompatibility graph. The frozen finite-state, horizon-one benchmark
also closes a continuous-action realization interval at `LB=UB=2`:

    python -m ncd certified-continuous --output runs/certified_continuous

formal run and the boundary of the claim.

## Version 0.9 OOD-guarded causal guidance

The `ood-guided` command adds five selection-only guard partitions for ID,
function, noise, scale, and intervention shifts. Causal reranking may select a
new program only when its ordinary validation objective and its frozen-teacher
fidelity in every guard are no lower than the historical candidate.

Formal seeds 1593/1594 each regenerated and replayed 12,800 worlds. In both
runs the historical program was the only candidate that passed every gate, so
the method abstained and all final-environment fidelity changes were exactly
zero. This establishes the implemented safety behavior on these two runs, but

## Version 0.10 structured mechanism extraction

`mechanism-search` compares the historical unconstrained greedy equation fit
with a hierarchy-constrained four-fold beam search on identical frozen neural
mechanism predictions. Each parent can contribute at most one unary operator;
interactions require both corresponding main effects.

Formal seeds 1793/1794 each covered 30 worlds across 3/5/8 nodes and five
environments and passed full replay. Pooled symbolic-to-neural NMSE fell from
0.111672 to 0.006023 (94.6%), while average nonconstant atoms fell from 2.261
to 0.849. The preregistered rule passed. See
`RESULTS_STRUCTURED_MECHANISM.md` and
`docs/STRUCTURED_MECHANISM_PROTOCOL.md`.

This result uses a supplied oracle DAG to isolate equation extraction. It
strengthens explicit SCM mechanism recovery but does not certify inferred graph
recovery or the complete neural-to-SCM objective.
Version 0.10.0 isolated-wheel acceptance is recorded in
`validation/wheel_v10_run/status.json`; all 94 regression tests passed.
